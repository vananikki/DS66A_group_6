# Credit Scoring – Lending Club

## 📌 Project Overview
This repository contains the **Midterm Project** for the Statistical Learning course (DS66A, Semester 5, Academic Year 2026–2027).  
Our group applies **Machine Learning algorithms and techniques** learned in class to solve a **business problem**: predicting credit scores and loan default risk using Lending Club data.

## 🎯 Objectives
- Apply ML knowledge (classification, regression, feature engineering, model evaluation) to a real-world dataset.  
- Build a predictive model for **credit scoring** that helps assess loan applicants’ risk.  
- Demonstrate improvements compared to existing public solutions (Kaggle, GitHub, blogs).  
- Deliver a complete project with **code, slides, and report in English**.
